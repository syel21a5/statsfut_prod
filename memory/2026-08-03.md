## Lições técnicas do dia (statsfut)
- SofaScore anti-bot: bloqueia por fingerprint TLS (curl puro morre) + IP de datacenter + exit nodes Tor de alguns países (US/DE/SE bloqueados; NL/FR/GB passam). curl_cffi impersonate=chrome120 é obrigatório.
- OLS (OpenLiteSpeed) lê /usr/local/lsws/conf/httpd_config.conf que faz include de /www/server/panel/vhost/openlitespeed/*.conf. httpd_config.conf.txt é dump (não lido). Vhost novo = arquivo .conf na pasta do painel + map nos listeners + reload (kill -USR1 no PID do lshttpd main; systemctl não gerencia — serviço inactive no systemd).
- OLS não faz Basic Auth em context proxy (só static); .htaccess AuthType ignorado. Basic Auth em Django = middleware condicional por env var (BASIC_AUTH_USER/PASS no .env, no-op sem a variável).
- SofaScore: tournament.id é a fase (ex: Clausura 156467); uniqueTournament.id é o torneio estável (155) — usar este para league_id.
- process_fixtures: league_map do update_live_matches precisa conhecer os nomes que a fonte manda (SofaScore: 'LigaPro Serie A', 'Copa Betano do Brasil'); nome desconhecido → continue silencioso (jogo some sem contar no resumo).
- FT stale: jogos Live que saem do radar do SofaScore e passaram de 2h → marcar FT (senão a home mostra jogo terminado como "em andamento").
- "Atq. Perigosos" é métrica exclusiva do Flashscore (SofaScore não tem) — fica 0 no radar.
- MySQL: usuário statsfut só enxerga o próprio banco (SHOW DATABASES não lista outros). Grant é por usuário@localhost (socket) — conexão TCP 127.0.0.1 é host separado.
